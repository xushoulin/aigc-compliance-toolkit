# 合规自检工具箱

面向 AI 微短剧制作方的发布前合规自检工具。四个模块：AI 标识核查、备案分层判定、授权凭证管理、AI 魔改风险提示。所有文件与数据仅在浏览器本地处理，不上传服务器。

## 技术栈

- Next.js 15 (App Router) + React 19
- TypeScript + Tailwind CSS v3

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000

## 构建

```bash
npm run build
npm start
```

## 功能模块

| 路径 | 功能 | 说明 |
|------|------|------|
| `/tools/ai-label` | AI 标识核查 | 本地扫描文件字节中的显式标识文字线索与元数据 AIGC 隐式标识字段；文本模式检查声明与位置 |
| `/tools/filing` | 备案分层判定 | 依《微短剧发展管理办法》（2026-09-01 施行）按投资额 + 题材判定一/二/三类；AI 剧与真人剧门槛不同 |
| `/tools/authorization` | 授权凭证管理 | 登记肖像/声音/IP/影视图素的授权来源与凭证，localStorage 本地存储，可导出 CSV 授权链证明 |
| `/tools/remake` | AI 魔改风险提示 | 关键词规则扫描四大名著、革命/英模、历史题材、颠覆性改动词、低俗擦边；只提示不定性 |

## 政策依据

- 《人工智能生成合成内容标识办法》（2025-09-01 施行）：显式 + 隐式双标识，禁止恶意删除/篡改/伪造/隐匿标识，禁止为此提供工具或服务。
- 《微短剧发展管理办法》（广电总局令第 16 号，2026-09-01 施行）：一类（特殊题材或 AI 剧投资 ≥80 万 / 真人 ≥300 万）、二类（AI 30–80 万 / 真人 100–300 万）、三类（AI <30 万 / 真人 <100 万）。
- 广电总局「AI 魔改」专项治理与 2026-11 新一轮低俗化同质化专项治理。

## 边界与免责

本工具只做「补合规」，不做「过审核」：不提供删除/篡改/伪造/隐匿 AI 标识的能力；不采集任何人的面部图像做相似度比对；不对作品是否违规下定性结论。结果仅供参考，不构成法律意见，最终以主管部门与平台认定为准。
